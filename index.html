Cài đặt

Cần IBus ≥ 1.5, GTK4 và Rust. Chọn cách cài phù hợp rồi làm theo từng bước.

Cách 1 — một dòng lệnh

1

Chạy trình cài đặt online

Tải mã nguồn, build và cài — udev rule và nhóm input được thiết lập tự động.

curl -fsSL https://raw.githubusercontent.com/fundokukiri/ibus-mangrs/dev/scripts/install-online.sh | sh

Cách 2 — từ mã nguồn

1

Build engine

Clone repo và build với GUI settings window.

git clone https://github.com/fundokukiri/ibus-mangrs
cd ibus-mangrs
cargo build --release --features gui
2

Cài & khởi động lại IBus

Engine vào /usr/lib/ibus-mangrs/, component đăng ký vào IBus.

sudo ./scripts/install.sh
ibus restart
3

Thêm nguồn nhập

Cài đặt → Bàn phím → Nguồn nhập → + → Tiếng Việt → MăngRS. Chuyển bố cục bằng Super+Space.

Gỡ cài đặt

1

Chạy trình gỡ

Gỡ engine, component và udev rule — giữ nguyên cấu hình của bạn tại ~/.config/ibus-mangrs/.

sudo ./scripts/uninstall.sh
ibus restart
2

Gỡ sạch nếu muốn

Xoá nốt cấu hình, macro, từ điển và tự xoá mình khỏi nhóm input nếu cần:

rm -rf ~/.config/ibus-mangrs ~/.cache/ibus-mangrs
sudo gpasswd -d $USER input
// Người dùng Arch gỡ bằng sudo pacman -R ibus-ibus-mangrs; nâng cấp chỉ cần chạy lại ./scripts/autoinstall.sh.

Macro & từ điển

File cấu hình nằm ở ~/.config/ibus-mangrs/, nạp lại nóng trong ~1 giây.

macros.toml — từ viết tắt

gs=giờ sáng
dc=địa chỉ: $TIME

$TIME/$DATE mở rộng theo định dạng trong GUI; key viết HOA thì giá trị cũng HOA.

dictionary.txt — từ không bao giờ tự khôi phục

nginx

Xử lý sự cố

Các lỗi hay gặp và cách xử lý nhanh.

Engine không xuất hiện trong Nguồn nhập
Chạy ibus write-cache --system rồi ibus-daemon -drx. Kiểm tra /usr/share/ibus/component/ibus-mangrs.xml tồn tại.
Dấu không hiện ở một ứng dụng cụ thể
Thêm App Rule cho tiến trình đó trong GUI (thẻ Applications), hoặc kiểm tra quyền /dev/uinput.
Từ tiếng Anh / tên biến bị biến đổi
Từ không phải tiếng Việt tự khôi phục về phím thô; nếu vẫn sai, thêm từ vào dictionary.txt và bật từ điển.
Chế độ uinput không chạy trên Wayland
Đúng thiết kế: chúng tự quay về preedit trên GNOME Wayland, dành cho phiên X11.
Báo lỗi thế nào cho dễ sửa?
Bật Debug Logging trong GUI, tái hiện lỗi, đính kèm ~/.cache/ibus-mangrs/debug.log vào GitHub issue — log không chứa chữ bạn gõ.
